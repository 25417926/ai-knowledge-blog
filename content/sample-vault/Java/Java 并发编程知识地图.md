# Java 并发编程知识地图

并发是 Java 后端面试与工程实践的分水岭。这张地图把并发拆成四条主线，每条线都能独立深入，但真正的难点在它们的交叉处。

## 四条主线

- **内存模型**：可见性、有序性、原子性从哪来。这层不清楚，后面所有结论都只是背诵。
- **线程与线程池**：任务提交后到底发生了什么，参数怎么定，拒绝策略怎么选。详见 [[JUC 线程池核心参数]]。
- **锁**：`synchronized` 的锁升级、`AQS` 的排队与唤醒、读写锁与乐观锁的取舍。
- **并发容器**：`ConcurrentHashMap` 的分段思想与扩容并发化。

## 一条实用建议

多数线上并发问题不是"锁没加对"，而是**线程池的队列把问题藏起来了**。请求堆积在无界队列里，直到 OOM 才暴露。所以排查时先看队列深度，再看锁竞争。
